The interface between the user and the system. Designing for usability, clarity, and efficiency. الواجهة بين المستخدم والنظام. التصميم من أجل قابلية الاستخدام (Usability)، الوضوح، والكفاءة.

Forms vs. Reports النماذج مقابل التقارير

Form النموذج (Form)

A business document that contains some predefined data and may include some areas where additional data are to be filled in. وثيقة عمل تحتوي على بعض البيانات المحددة مسبقاً وقد تتضمن مناطق لملء بيانات إضافية.

  • Flow: User $\to$ System (Input). التدفق: المستخدم $\to$ النظام (إدخال).
  • Example: Product Order Form, Employment Application. مثال: نموذج طلب منتج، طلب توظيف.
  • Focus: Data Entry & Modification. التركيز: إدخال وتعديل البيانات.

Report التقرير (Report)

A business document that contains only predefined data; it is a passive document used solely for reading or viewing. وثيقة عمل تحتوي فقط على بيانات محددة مسبقاً؛ وهي وثيقة سلبية تستخدم فقط للقراءة أو العرض.

  • Flow: System $\to$ User (Output). التدفق: النظام $\to$ المستخدم (إخراج).
  • Example: Invoice, Weekly Sales Summary. مثال: فاتورة، ملخص المبيعات الأسبوعي.
  • Focus: Data Presentation & Decision Support. التركيز: عرض البيانات ودعم القرار.

The Design Process عملية التصميم

1. Requirements 1. المتطلبات

Understand user, task, and environment. فهم المستخدم، المهمة، والبيئة.

2. Structuring 2. الهيكلة

Initial prototype (Paper or Wireframe). نموذج أولي (ورقي أو Wireframe).

3. Usability 3. قابلية الاستخدام

Test with users and refine. الاختبار مع المستخدمين والتحسين.

Key Deliverable: Design Specifications المخرج الرئيسي: مواصفات التصميم

1. Narrative Overview: Why does this exist? Who uses it? 1. نظرة عامة سردية: لماذا يوجد هذا؟ من يستخدمه؟
2. Sample Design: Visual layout. 2. تصميم عينة: التخطيط البصري.
3. Testing & Usability: How will we know it works? 3. الاختبار وقابلية الاستخدام: كيف سنعرف أنه يعمل؟

Formatting Guidelines إرشادات التنسيق

Meaningful Titles عناوين ذات معنى

Clear, specific titles. Include revision date/code to distinguish versions. عناوين واضحة ومحددة. قم بتضمين تاريخ المراجعة/الرمز لتمييز النسخ.

Meaningful Information معلومات ذات معنى

Only display what is necessary. Do not clutter. Information should be usable without modification. اعرض فقط ما هو ضروري. لا تكدس المعلومات. يجب أن تكون المعلومات قابلة للاستخدام دون تعديل.

Balanced Layout تخطيط متوازن

Balance information on the screen. Ensure adequate spacing and margins. Use standard navigation. وازن المعلومات على الشاشة. تأكد من وجود مسافات وهوامش كافية. استخدم تنقلاً قياسياً.

Easy Navigation سهولة التنقل

Clearly show how to move forward/backward. Follow user's mental model (e.g., Tab order matches reading order). أظهر بوضوح كيفية التحرك للأمام/الخلف. اتبع النموذج الذهني للمستخدم (مثلاً: ترتيب زر Tab يطابق ترتيب القراءة).

Assessing Usability تقييم قابلية الاستخدام (Usability)

The overall evaluation of how a system performs in supporting a particular user for a particular task. التقييم الشامل لأداء النظام في دعم مستخدم معين لمهمة معينة.

TRAP: Forms vs Reports فخ: النماذج مقابل التقارير

Form: Input mechanism (Write).
Report: Output mechanism (Read-only).
A "Turnaround Document" is a Report that becomes a Form (e.g., a bill stub you tear off and return). النموذج (Form): آلية إدخال (كتابة).
التقرير (Report): آلية إخراج (قراءة فقط).
"Turnaround Document" هو تقرير يتحول إلى نموذج (مثل كعب الفاتورة الذي تفصله وتعيده).

TRAP: Prototyping فخ: النمذجة (Prototyping)

Design is rarely done on paper alone anymore. We build prototypes. However, don't test with real data initially. Use realistic dummy data to test the layout without distraction. نادراً ما يتم التصميم على الورق فقط الآن. نبني نماذج أولية. ومع ذلك، لا تختبر ببيانات حقيقية في البداية. استخدم بيانات وهمية (Dummy Data) واقعية لاختبار التخطيط دون تشتيت.

SECRET: Highlighting Rule سر: قاعدة التمييز (Highlighting Rule)

The rule of thumb for highlighting is Use Sparingly. If everything is bold/red, nothing is important. It loses its impact and fatigues the user. القاعدة الذهبية للتمييز هي استخدمه باعتدال (Use Sparingly). إذا كان كل شيء عريضاً/أحمر، فلا شيء مهم. يفقد تأثيره ويرهق المستخدم.

KEY CONCEPT: Measures of Usability مفهوم أساسي: مقاييس قابلية الاستخدام

Memorize the 3 key measures:
1. Time to Learn: How fast can they master it?
2. Speed of Performance: How fast can they work?
3. Rate of Errors: How many mistakes do they make? احفظ المقاييس الثلاثة الرئيسية:
1. وقت التعلم: كم سرعة إتقانهم له؟
2. سرعة الأداء: كم سرعة عملهم؟
3. معدل الأخطاء: كم عدد الأخطاء التي يرتكبونها؟
