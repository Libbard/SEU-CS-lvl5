The Project Manager مدير المشروع (The Project Manager)

A Project Manager is a systems analyst with a diverse set of skills: management, leadership, technical, conflict management, and customer relationship management. مدير المشروع هو محلل نظم يتمتع بمجموعة متنوعة من المهارات: الإدارة، القيادة، التقنية، إدارة النزاعات، وإدارة علاقات العملاء.

They are responsible for initiating, planning, executing, and closing down a project. Their focus changes over the life of the project: هم مسؤولون عن بدء، تخطيط، تنفيذ، وإغلاق المشروع. يتغير تركيزهم على مدار حياة المشروع:

Early Phases المراحل المبكرة Technique & Innovation التقنية والابتكار
Later Phases المراحل المتأخرة Management & Control الإدارة والتحكم

The Project Management Process عملية إدارة المشروع

1. Initiation 1. الاستهلال (Initiation)

Start the Engine بدء المحرك

  • Establish the Initiation Team. تأسيس فريق الاستهلال.
  • Establish relationships with customers. تأسيس العلاقات مع العملاء.
  • Establish the Project Initiation Plan. وضع خطة استهلال المشروع.
  • Outcome: Project Charter. المخرج: ميثاق المشروع (Project Charter).

2. Planning 2. التخطيط (Planning)

The Roadmap خارطة الطريق

  • Describe Scope, Alternatives, and Feasibility. وصف النطاق، البدائل، والجدوى.
  • Divide project into manageable tasks (WBS). تقسيم المشروع لمهام قابلة للإدارة (WBS).
  • Estimate resources and create a Preliminary Schedule (Gantt/PERT). تقدير الموارد وإنشاء جدول أولي (Gantt/PERT).
  • Outcome: Baseline Project Plan. المخرج: خطة المشروع الأساسية (Baseline Project Plan).

3. Execution 3. التنفيذ (Execution)

Doing the Work إنجاز العمل

  • Execute the Baseline Project Plan. تنفيذ خطة المشروع الأساسية.
  • Monitor progress against the Baseline Plan. مراقبة التقدم مقابل الخطة الأساسية.
  • Manage changes to the Baseline Plan. إدارة التغييرات على الخطة الأساسية.
  • Maintain the Project Workbook. صيانة كتيب المشروع (Project Workbook).

4. Closedown 4. الإغلاق (Closedown)

Finalizing الإنهاء

  • Close down the project (terminate contracts). إغلاق المشروع (إنهاء العقود).
  • Conduct post-project reviews. إجراء مراجعات ما بعد المشروع.
  • Close the customer contract. إغلاق عقد العميل.

Scheduling Tools أدوات الجدولة (Scheduling Tools)

Gantt Charts مخططات غانت (Gantt Charts)

  • Show task durations as bars. إظهار مدد المهام كأشرطة.
  • Show time overlap. إظهار التداخل الزمني.
  • Can show slack time. يمكن إظهار وقت الركود (Slack).
  • Best for: Tracking progress and simple schedules. الأفضل لـ: تتبع التقدم والجداول البسيطة.

Network Diagrams (PERT/CPM) مخططات الشبكة (PERT/CPM)

  • Show task dependencies (precedence). إظهار اعتماديات المهام (الأسبقية).
  • Show parallelism. إظهار التوازي.
  • Used to calculate the Critical Path. تستخدم لحساب المسار الحرج (Critical Path).
  • Best for: Complex projects with many dependencies. الأفضل لـ: المشاريع المعقدة ذات الاعتماديات الكثيرة.

Estimating Task Duration تقدير مدة المهمة

In PERT (Program Evaluation Review Technique), we use a weighted average of three estimates to calculate expected time ($ET$): في PERT، نستخدم متوسطاً مرجحاً لثلاثة تقديرات لحساب الوقت المتوقع ($ET$):

$o$ Optimistic متفائل
+
$p$ Pessimistic متشائم
+
$4r$ Realistic واقعي
=
$ET = \frac{o + 4r + p}{6}$ Expected Time الوقت المتوقع

TRAP: The Critical Path فخ: المسار الحرج (Critical Path)

"Is the Critical Path the shortest path?"
NO. It is the longest path through the network. It dictates the shortest possible time to complete the project. If any task on the critical path is delayed, the whole project is delayed. "هل المسار الحرج هو المسار الأقصر؟"
لا. إنه المسار الأطول عبر الشبكة. يحدد أقصر وقت ممكن لإكمال المشروع. إذا تأخرت أي مهمة على المسار الحرج، يتأخر المشروع بأكمله.

TRAP: Slack Time فخ: وقت الركود (Slack Time)

Tasks on the Critical Path have Zero Slack. Slack is the amount of time a task can be delayed without delaying the project.
$Slack = T_L - T_E$ (Latest finish - Earliest finish). المهام على المسار الحرج لديها صفر ركود. الركود هو مقدار الوقت الذي يمكن أن تتأخر فيه المهمة دون تأخير المشروع.
$Slack = T_L - T_E$ (أحدث نهاية - أبكر نهاية).

SECRET: Baseline vs Actual سر: الأساسي مقابل الفعلي

The Baseline Project Plan is what you planned at the start. The Actual is what really happened. A Project Manager's main job during Execution is monitoring the deviation between these two. خطة المشروع الأساسية (Baseline) هي ما خططت له في البداية. الفعلي (Actual) هو ما حدث بالفعل. وظيفة مدير المشروع الرئيسية أثناء التنفيذ هي مراقبة الانحراف بين الاثنين.

KEY CONCEPT: WBS مفهوم مفتاحي: WBS

You cannot build a schedule (Gantt/PERT) without a Work Breakdown Structure (WBS) first. The WBS identifies *what* needs to be done (the tasks). The schedule decides *when* (the timing). لا يمكنك بناء جدول (Gantt/PERT) دون هيكل تقسيم العمل (WBS) أولاً. يحدد WBS *ما* يجب القيام به (المهام). يقرر الجدول *متى* (التوقيت).
