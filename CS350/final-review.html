A complete synthesis of Modules 7 through 13. Mastering SQL, Relational Algebra, Normalization, and Security.

Covering Modules 7-13

07. SQL Definition

DDL & Constraints

Creating Structures

CREATE TABLE defines the schema. ALTER TABLE modifies it (add/drop columns). DROP TABLE deletes it.

Constraint Actions

When deleting a parent record, what happens to the children?

  • RESTRICT: Stop deletion (Default).
  • CASCADE: Delete children too.
  • SET NULL: Set child FK to NULL.

08. SQL Retrieval

DML & Basics

The SELECT Block

SELECT columns
FROM tables
WHERE row_condition
ORDER BY sort_cols;

Pattern Matching

  • LIKE: Used for strings.
  • %: Multi-char wildcard.
  • _: Single-char wildcard.

09. Complex SQL

Joins & Logic

Advanced Joins

  • Inner Join: Only matching rows.
  • Left/Right Outer Join: Keep all rows from one side, fill missing matches with NULL.
  • Self Join: Joining table to itself (Requires Aliases).

Grouping

WHERE filters rows before grouping.
HAVING filters groups after grouping (allows Aggregates).

10. Theory & Views

Relational Algebra

Relational Algebra Ops

$\sigma$ Select: Filter Rows.
$\pi$ Project: Filter Cols.
$\times$ Product: All combos.
$\div$ Division: "For All".

Views

Virtual tables. Saved queries. Hides complexity and enhances security. Generally read-only if they contain aggregates or joins.

11. Normalization I

1NF - 3NF

The Basics

  • 1NF: Atomic values (No lists).
  • 2NF: No Partial Dependency (Attribute depends on full PK).
  • 3NF: No Transitive Dependency (Non-key depends on Non-key).

Functional Dependency

$X \to Y$: If you know X, you determine Y.
Armstrong's Axioms: Reflexive, Augmentation, Transitive.

12. Normalization II

BCNF - 5NF

Advanced Forms

  • BCNF: Stricter 3NF. Every determinant must be a Superkey.
  • 4NF: No Multivalued Dependencies (MVD).
  • 5NF: Join Dependencies (Rare).

Decomposition Properties

Lossless Join: Rejoining tables must not create fake data.
Dependency Preservation: FDs should be enforceable within a single table.

13. Database Security

Access Control

Access Models

  • DAC: Identity-based (GRANT/REVOKE).
  • MAC: Clearance Levels (Top Secret). No Read Up, No Write Down.
  • RBAC: Role-based (Manager, Clerk).

CIA Triad

Confidentiality Integrity Availability

SQL Injection

Malicious code inserted via inputs.
Solution: Prepared Statements (Bind Variables).

SQL Order of Execution

SQL code is written in one order but executed in another.

1. FROM / JOIN
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT
6. DISTINCT
7. ORDER BY

The Final Exam Mega Vault

Secrets for Mod 7-13

TRAP: 3NF vs BCNF

If $X \to A$ and $X$ is NOT a superkey:
In 3NF: Allowed if $A$ is Prime.
In BCNF: Forbidden. $X$ MUST be a superkey.

TRAP: WHERE vs HAVING

You cannot use Aggregates (SUM, COUNT) in WHERE.
Wrong: `WHERE COUNT(*) > 5`
Right: `HAVING COUNT(*) > 5`

TRAP: NULL Comparisons

`Salary = NULL` is always FALSE (or Unknown).
You MUST use `Salary IS NULL`.

SECRET: The Division Op

Any question with "Find students who took ALL courses" implies the Division ($\div$) operation. In SQL, this is solved using double `NOT EXISTS`.

SECRET: MAC Logic

Bell-LaPadula (Confidentiality):
No Read Up (Can't see above).
No Write Down (Can't leak to below).

SECRET: Lossless Join

Decomposition is only valid if it is Lossless. This means the common attribute between the two new tables MUST be a key in at least one of them.
