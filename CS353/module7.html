Heaps: The Binary Tree in an Array

Definition

A Heap is a binary tree with two critical properties:

  • Structural Property: It is Essentially Complete. All levels are full except possibly the last, which is filled from left to right. This allows implementation as an ARRAY.
  • Parental Dominance: The key at every node is $\ge$ (or $\le$ for min-heap) the keys of its children.

Heap Construction

The "Heapify" Process

We don't insert elements one by one ($O(n \log n)$). Instead, we dump data into an array and fix it Bottom-Up.

  1. Start at the last parent node (index $\lfloor n/2 \rfloor$).
  2. Check if the parent dominates its children.
  3. If not, Swap with the larger child (sift down).
  4. Move backwards to index 1.
Efficiency: $O(n)$

Surprisingly, building a heap is linear time, not log-linear.

Heapsort: The 2-Stage Algorithm

1

Stage 1: Construction

Construct a heap from the given array using the Bottom-Up approach.


Cost: $O(n)$
2

Stage 2: Root Deletion

1. Swap Root (Max) with Last Element.
2. Decrease heap size by 1.
3. Sift down the new root.
4. Repeat $n-1$ times.

Cost: $O(n \log n)$
Total Complexity: $O(n \log n)$

Space Complexity: $O(1)$ (In-place)

Problem Reduction

"If you can't solve a problem, transform it into one you can solve."

LCM via GCD

Finding the Least Common Multiple (LCM) is hard. Finding GCD (Euclid's) is easy.

LCM(u, v) = (u * v) / GCD(u, v)

Counting Paths

Count paths of length $n$ in a graph? Reduce it to Matrix Multiplication. Compute $A^n$ (Adjacency Matrix to power $n$).

Linear Programming

Many optimization problems (Network Flow, Knapsack) can be reduced to a standard Linear Programming model and solved using Simplex.

The Exam Vault

Professor's Secrets & Trap Avoidance

TRAP: Heap vs BST

A Heap is NOT a Binary Search Tree.
BST: Left < Parent < Right.
Heap: Parent > Children (Left AND Right).
Heaps are ordered top-to-bottom,
BSTs left-to-right. Don't confuse them!

TRAP: Array Indices

In algorithm theory, arrays often start at index 1 for easier math (Left child = $2i$, Right = $2i+1$).
In C++/Java, they start at 0 (Left = $2i+1$, Right = $2i+2$). Check the context of the question!

SECRET: Construction Speed

Constructing a heap using `HeapInsert` $n$ times takes $O(n \log n)$. Using the Bottom-Up approach takes $O(n)$.
This linear time construction is the "secret sauce" of Heapsort efficiency.

KEY CONCEPT: Reduction Direction

Always reduce the Unknown problem TO the Known problem.
Correct: "I can solve LCM by reducing it to GCD."
Incorrect: "I can solve GCD by reducing it to LCM."
