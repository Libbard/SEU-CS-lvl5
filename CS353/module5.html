Divide-and-Conquer

The most famous algorithm design paradigm. Divide the problem into equal sub-problems, solve them recursively, and combine the results.

Mergesort Quicksort Master Theorem Strassen's Matrix

The Strategy & Analysis

The 3-Step Process

  • 1

    Divide

    Split problem into several subproblems of the same type (ideally equal size).

  • 2

    Conquer

    Solve subproblems recursively.

  • 3

    Combine

    Merge solutions to get the original answer.

The Master Theorem

For recurrence $T(n) = aT(n/b) + f(n)$ where $f(n) \in O(n^d)$:

Case 1: $a < b^d$ $T(n) \in O(n^d)$
Case 2: $a = b^d$ $T(n) \in O(n^d \log n)$
Case 3: $a > b^d$ $T(n) \in O(n^{\log_b a})$

The Sorting Titans

Mergesort

Stable

Divides array into two halves, sorts recursively, then merges sorted halves.

Recurrence: $T(n) = 2T(n/2) + cn$
Complexity: $O(n \log n)$ (Always)
Drawback: Requires $O(n)$ extra space.

Quicksort

In-place

Divides based on a pivot. Elements $<$ pivot go left, $>$ pivot go right. Then sorts partitions.

Best/Avg: $O(n \log n)$
Worst: $O(n^2)$ (Sorted Array)
Note: Faster than Mergesort on random data.

Advanced Applications

Large Integer Multiplication

Brute force multiplication takes $O(n^2)$. By using a algebraic trick to compute $(A_1+A_2)(B_1+B_2)$, we reduce multiplications from 4 to 3.

Recurrence: $T(n) = 3T(n/2)$ $O(n^{1.585})$

Strassen's Matrix Multiplication

Standard matrix multiplication takes $O(n^3)$ (8 mults for 2x2). Strassen found a way to do it with 7 multiplications.

Recurrence: $T(n) = 7T(n/2)$ $O(n^{2.807})$

Binary Tree Traversals

Recursive algorithms defined by when the Root is visited .

Preorder

Root $\to$ Left $\to$ Right

Inorder

Left $\to$ Root $\to$ Right

Postorder

Left $\to$ Right $\to$ Root

The Exam Vault

Professor's Secrets & Trap Avoidance

TRAP: Quicksort's Worst Case

"Is Quicksort always $O(n \log n)$?"
NO! If the array is already sorted (or reverse sorted) and you pick the first element as pivot, it degrades to $O(n^2)$. This is the most common trick question .

TRAP: Mergesort Space

Mergesort is "perfect" in time ($O(n \log n)$), but it is NOT in-place. It requires $O(n)$ extra auxiliary space for the merge step. If memory is tight, QuickSort is preferred .

SECRET: Master Theorem Shortcut

Compare $a$ vs $b^d$.
If $a > b^d$, the recursion (leaves) dominates ($O(n^{\log_b a})$).
If $a < b^d$, the work at root dominates ($O(n^d)$).
If equal, multiply by $\log n$ ($O(n^d \log n)$).

KEY CONCEPT: Strassen's Limit

Strassen's algorithm ($O(n^{2.8})$) is asymptotically faster than Brute Force ($O(n^3)$), but it has a huge constant factor. It is only faster in practice for very large matrices ($N > 100$) .
