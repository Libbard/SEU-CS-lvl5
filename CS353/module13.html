Coping with Limitations

When a problem is NP-Hard, we have two choices: find an exact solution intelligently (Backtracking/Branch-and-Bound) or settle for a "good enough" approximation.

Backtracking State-Space Trees Branch-and-Bound Approximation Algorithms

Two Approaches to NP-Hard Problems

1. Exact Solutions

We want the optimal answer, even if it takes a long time. We try to be smarter than Brute Force by eliminating bad options early.

  • Backtracking: Depth-First Search with pruning.
  • Branch-and-Bound: Optimization with bounding functions.

2. Approximations

We accept a sub-optimal answer if we can find it in Polynomial Time.

  • Accuracy Ratio: How close are we to optimal?
  • Heuristics: Greedy strategies (Nearest Neighbor).

Backtracking

Builds the solution component by component (e.g., $x_1, x_2, \dots, x_n$). If a partial solution $(x_1, \dots, x_i)$ cannot lead to a complete valid solution, we Prune that node (terminate that branch) and backtrack to try a different choice for $x_i$.

N-Queens Problem

Place $n$ queens on an $n \times n$ board so no two attack each other.
Constraint: No two queens share a row, column, or diagonal.

Hamiltonian Circuit

Find a cycle visiting every vertex exactly once. Backtracking explores paths and prunes if a vertex is visited twice or no edge exists.

Branch-and-Bound

Similar to Backtracking but used for Optimization Problems (finding the best solution, not just any solution).

Key Components

  • Bounding Function: Calculates a lower (for minimization) or upper (for maximization) bound on the optimal solution obtainable from a node.
  • Pruning Rule: If a node's bound is worse than the best solution found so far, kill the node.

Approximation Algorithms

Performance Ratio ($\rho$)

We measure quality by the ratio of the approximate solution cost ($f(s_a)$) to the optimal cost ($f(s^*)$).

$\rho(n) = \frac{f(s_a)}{f(s^*)}$ (for minimization)

TSP: Nearest Neighbor

Greedy

Strategy: Always go to the nearest unvisited city.
Accuracy: For general graphs, the error is unbounded (can be $\infty$). For Euclidean graphs (triangle inequality holds), it satisfies $\rho(n) \le \frac{1}{2}(\lceil \log_2 n \rceil + 1)$.

Knapsack: Greedy Ratio

Greedy

Strategy: Sort items by value-to-weight ratio ($v_i/w_i$) and pick the best ones.
Accuracy: The performance ratio is bounded (usually $\le 2$).

The Exam Vault

Professor's Secrets & Trap Avoidance

TRAP: Worst Case Backtracking

"Is Backtracking efficient?"
In practice, yes (it prunes many branches). But in the Worst Case, it visits every node, so it is still Exponential ($O(2^n)$ or $O(n!)$). Do not call it "Polynomial Time".

TRAP: Approximation Ratio

For maximization problems (Knapsack), the ratio is usually defined as $f(s^*)/f(s_a) \ge 1$. For minimization (TSP), it is $f(s_a)/f(s^*) \ge 1$. Always check the direction of the inequality so your ratio is $\ge 1$.

SECRET: B&B vs Backtracking

Backtracking is for non-optimization (decision) problems or finding all solutions.
Branch-and-Bound is for optimization problems (Min/Max). It uses the numeric bound to prune. This distinction is crucial for definitions.

KEY CONCEPT: Multifragment Heuristic

For TSP, another approximation is the Multifragment Heuristic. It sorts edges by weight (like Kruskal's) and adds them if they don't create a loop (unless size < n) and don't create a degree-3 vertex. It often outperforms Nearest Neighbor.
