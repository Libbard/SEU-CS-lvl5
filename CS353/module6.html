Transform-and-Conquer

Solve a difficult problem by transforming it into a simpler or more convenient form. "If you can't solve the problem, change the problem."

Presorting Gaussian Elimination AVL Trees Heaps

The Three Variations

1

Instance Simplification

Transform the instance into a simpler/more convenient property.

Ex: Presorting, Gaussian Elim.

2

Representation Change

Transform the instance into a different representation.

Ex: AVL Trees, Heaps, 2-3 Trees.

3

Problem Reduction

Transform the problem into a totally different problem for which an algorithm is known.

Ex: LCM via GCD, Linear Prog.

Presorting

Many problems become trivial if the input array is sorted first. The cost of sorting ($O(n \log n)$) is often justified if it avoids an $O(n^2)$ brute-force solution.

Problem Brute Force Presorting Approach Total Efficiency
Element Uniqueness $O(n^2)$ Sort, then check neighbors ($A[i] == A[i+1]$). $O(n \log n)$
Computing Mode $O(n^2)$ Sort, then find longest run of equal values. $O(n \log n)$
Searching $O(n)$ Sort, then Binary Search. $O(n \log n)$ + $O(\log n)$

Gaussian Elimination

Used to solve systems of linear equations $Ax = b$, find matrix inverses, or computing determinants.

The Transformation

Transform the matrix $A$ into an Upper Triangular Matrix (all zeros below diagonal) using elementary row operations. Then solve via backward substitution.

Complexity: $\Theta(n^3)$ Expensive but standard.
Original
$$ \begin{bmatrix} 2 & 1 & 1 \\ 4 & -6 & 0 \\ -2 & 7 & 2 \end{bmatrix} $$
Upper Triangular
$$ \begin{bmatrix} 2 & 1 & 1 \\ 0 & -8 & -2 \\ 0 & 0 & 1 \end{bmatrix} $$

AVL Trees

The Problem with standard BST

If you insert sorted data ($1, 2, 3, 4, 5$) into a Binary Search Tree, it becomes a linked list (skewed). Search becomes $O(n)$ instead of $O(\log n)$.

AVL Tree (Adelson-Velsky and Landis)

A BST that maintains Balance. For every node, the height difference between left and right subtrees (Balance Factor) must be $-1, 0, \text{ or } 1$. If it becomes $\pm 2$, we Rotate.

Single Rotation

Used for LL or RR imbalance. One move fixes the tree.

Double Rotation

Used for LR or RL imbalance. Two moves (Left-Right or Right-Left) required.

The Exam Vault

Professor's Secrets & Trap Avoidance

TRAP: Presorting Cost

"If we presort the array, searching is $O(\log n)$."
Technically true, but misleading. The total cost is Sort + Search = $O(n \log n) + O(\log n) = O(n \log n)$. Do not ignore the sorting cost in your analysis.

TRAP: Gaussian Division

In Gaussian Elimination, we divide by the pivot $A[i,i]$. If $A[i,i] = 0$, the algorithm fails. We must swap rows (Partial Pivoting) to fix this. This is a common "edge case" exam question.

SECRET: AVL vs Red-Black

AVL trees are strictly balanced (height diff $\le 1$). Red-Black trees are loosely balanced (height diff up to factor of 2). AVL provides faster lookups, but slower insertions/deletions due to frequent rotations.

KEY CONCEPT: LU Decomposition

Gaussian Elimination effectively decomposes matrix $A$ into Lower ($L$) and Upper ($U$) triangular matrices ($A = LU$). This transformation allows solving $Ax=b$ quickly for multiple different vectors $b$.
