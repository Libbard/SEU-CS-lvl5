Persistence: Mass-Storage Systems

Managing Secondary Storage. HDD vs SSD mechanics, Disk Scheduling algorithms, and RAID redundancy.

Physical Storage

Hard Disk Drive (HDD)

Mechanical device. Magnetic platters spin under a moving read-write arm.

  • Track: Concentric circle on a platter.
  • Sector: Smallest unit of transfer (e.g., 512 bytes).
  • Cylinder: Set of tracks at same arm position across all platters.
  • Seek Time: Time to move arm to cylinder. (Major bottleneck).

Non-Volatile Memory (NVM)

Electrical device. No moving parts. Faster, more reliable, less power. Used in SSDs, USBs.

  • Flash NAND: Data stored in cells.
  • Write Endurance: Cells wear out after many writes.
  • Garbage Collection: NVM cannot overwrite directly; must erase block first. Valid data in block is copied elsewhere, then block is erased.

HDD Scheduling

The OS must minimize seek time. Given a queue of requests (e.g., Cylinders 98, 183, 37...), which one to serve next?

FCFS (First-Come First-Served)

Fair, but slow. Head swings wildly across the disk.

SCAN (Elevator Algorithm)

Disk arm starts at one end and moves toward the other, servicing requests. At the end, it reverses direction.

C-SCAN (Circular SCAN)

Like SCAN, but when it reaches the end, it immediately returns to the beginning without servicing requests on the return trip.
Provides more uniform wait time.

Device Management

Formatting

  • Low-Level (Physical) Formatting: Dividing disk into sectors. Done at factory.
  • Partitioning: Dividing disk into groups of cylinders (e.g., C:, D:).
  • Logical Formatting: Making a file system (NTFS, EXT4). Initializing data structures.

Swap-Space Management

Extension of main memory.

Can be a raw partition (faster, no FS overhead) or a large file in the file system (easier to resize).

RAID (Redundant Array of Independent Disks)

Using multiple disks together to improve Reliability (Redundancy) and Performance (Parallelism).

RAID 0 Striping

Data spread across disks.
+ Very Fast.
- No Redundancy (1 failure = data loss).

RAID 1 Mirroring

Copy data to second disk.
+ Very Reliable.
- Expensive (Uses 50% capacity).

RAID 5 Parity

Striping with Parity distributed across disks.
+ Good balance of Speed, Space, and Safety.
Can survive 1 disk failure.

The Exam Vault

Professor's Secrets & Trap Avoidance

TRAP: Seek vs Latency

Seek Time: Moving the ARM to the correct cylinder (Mechanical, Slow).
Rotational Latency: Waiting for the SECTOR to spin under the head.
Scheduling algorithms (SCAN) optimize Seek Time, not Latency.

TRAP: RAID Reliability

RAID protects against Disk Failure (Hardware), not human error, virus, or fire.
It is NOT a backup solution. You still need backups.

SECRET: SSD Scheduling

Disk scheduling algorithms (SCAN, C-SCAN) are useless for SSDs because SSDs have no moving parts. Random access is as fast as sequential access. The OS typically uses simple FCFS or merging for SSDs.

KEY CONCEPT: Boot Block

The computer starts by running the Bootstrap program from ROM. This program must know how to load the full OS from disk. The OS is stored in the Boot Block (usually first sector) of the storage device.
