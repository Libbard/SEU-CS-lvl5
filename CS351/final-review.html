Modules 7-13

Module 7: Main Memory

Address Binding

Mapping code to physical addresses.

  • Compile Time: Absolute code. If start location changes, recompile.
  • Load Time: Relocatable code. Final binding when loaded.
  • Execution Time: Binding delayed until run time. Needs MMU (Relocation Register).
Physical Addr = Logical Addr + Relocation Register

Fragmentation

External Total memory exists, but not contiguous.
Solved by Paging.
Internal Allocated memory is slightly larger than requested.
Unavoidable in Paging.

Module 8: Virtual Memory

Effective Access Time (EAT)

The performance of Demand Paging relies on the Page Fault Rate ($p$).

$$EAT = (1 - p) \times \text{mem\_access} + p \times \text{fault\_overhead}$$

*Fault overhead includes: Interrupt, Read Page (Disk I/O), Restart Process. Disk I/O (~8ms) is millions of times slower than RAM (~100ns).

Replacement Algos

  • FIFO: Oldest out. Suffers Belady's Anomaly.
  • Optimal: Replace page used furthest in future. (Benchmark only).
  • LRU: Replace least recently used. (Best approximation).
  • Thrashing: Busy swapping pages. $\sum$ Locality > Total Memory.

Disk Scheduling

Goal: Minimize Seek Time (Arm movement).

  • FCFS: Fair, but head jumps around wildly.
  • SCAN (Elevator): Head moves end-to-end. Biased distribution.
  • C-SCAN (Circular): Head moves end-to-end, then jumps back to start immediately. Provides Uniform Wait Time.

Module 10: I/O Systems

Polling

Busy-wait loop. Good for fast devices. Wasteful for slow ones.

Interrupts

Device signals CPU. CPU saves state, runs handler. Good for slow devices.

DMA

Direct Memory Access. Controller writes block to memory. Interrupt only at end.

PROFESSOR'S SECRETS

The Mega Vault: Final Exam Edition

Belady's Anomaly

Happens ONLY in FIFO. Increasing frame count can INCREASE page faults. Does NOT happen in LRU/Optimal (Stack Algorithms).

TLB Flush

Context Switching requires Flushing the TLB because virtual addresses of the new process map to different physical frames. This makes switching expensive.

DMA & Caches

DMA writes directly to RAM, bypassing CPU Cache. This causes Cache Incoherency (CPU sees stale data). Hardware must invalidate cache lines.

Modify Bit

During Page Replacement, check the Modify (Dirty) Bit. If 0, no need to write back to disk. Saves 50% I/O overhead.

Hard vs Soft Link

Hard Link: Points to Inode. Valid if original file deleted. Soft Link: Points to Path. Broken (dangling) if original file deleted.

RAID Parity

RAID 5 protects against 1 Disk Failure. It is NOT a backup. It protects Availability, not Data Integrity against corruption/virus.
